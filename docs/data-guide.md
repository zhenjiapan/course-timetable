# 课程数据维护指南

编辑 `data/fall-2026.ts`，不要直接修改 `out/` 中的文件。

## 字段

| 字段 | 含义 |
| --- | --- |
| day | Monday 至 Sunday |
| start / end | 24 小时制 HH:MM；结束必须晚于开始，当前网格范围 08:00–22:00 |
| name | 课程代码与班别，例如 AIE 1001 - L03 |
| type | 学校使用的课程类型名称 |
| location | 地点名称 |
| locationImage | public 下图片的站点路径，如 /images/locations/aie-1001-l03.jpg |
| audit | true 为旁听，false 为正式课程 |
| courseName / description | 课程名称与简介，可选 |
| credits / grading | 学分显示文字与评分方式，可选 |
| teacher | 教师姓名，可选 |
| homepage / homepages | 单个或多个教师主页，可选 |

每次上课是一条记录。同一课程多次上课时，课程简介等字段仍需保持一致；未来多学期扩展时可进一步拆成课程目录与上课安排。新增课程按星期、开始时间排序，同一星期、开始时间和课程代码组合必须唯一。

## 图片

相同内容已合并为共享文件。现有文件名沿用课程代码来源，不能据此推断照片的具体教室。换成按建筑命名之前，请核对照片真实内容。多门课程可引用同一张图片。建议使用适合屏幕显示的尺寸，并注明拍摄者或来源。

## 验证

运行 `npm run lint`、`npm run typecheck`、`npm test` 和 `npm run build`。用 `npm start` 预览生成的网站，检查：

1. 手机宽度下逐日切换，包括无课日期。
2. 桌面端时间位置和长短课程卡片。
3. Tab 聚焦课程，Enter 打开详情，Escape 关闭并返回原焦点。
4. 图片、教师链接和正式/旁听标识。

当前测试不验证教师网站内容或课程信息的真实性。更新学期时同步修改页面标题、metadata 和 README。请另行记录资料来源、实际核实日期及自己的贡献，不要将课程简介当作个人研究成果。
